## 🧠 Topics Covered

- **Core Java** — Variables, Operators, Arrays, Varargs, Command-line args
- **Object-Oriented Programming** — Classes, Objects, Inheritance, Encapsulation, Polymorphism, Interfaces, Abstract Classes
- **Data Structures** — Arrays, Doubly Linked List, Heap, Hashing
- **Collections Framework** — List, Map, Set
- **Multithreading** — Thread creation, synchronization basics

## 🚀 Getting Started

### Prerequisites
- Java JDK 8 or higher
- Any IDE (IntelliJ IDEA, Eclipse, VS Code) or terminal

### Run a file
```bash
# Compile
javac filename.java

# Run
java filename
```
